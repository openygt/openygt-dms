## 2. 模块架构

### 2.1 模块总览（9模块）

```
openygt-dms/                          # Maven 父项目
├── dms-common/                       # 公共基础（DTO/接口/枚举/异常）
├── dms-masterdata/                   # 基础数据（医院、煎药方案）
├── dms-system/                       # 系统管理（用户、配置、日志）
├── dms-equipment/                    # 设备管理（IoT接入、MQTT、适配器）
├── dms-production/                   # 生产执行（处方、任务状态机、工序）
├── dms-quality/                      # 质量管理（质检记录、追溯）
├── dms-print/                        # 打印中心（打印队列、重试）
├── dms-analytics/                    # 运营分析（报表、仪表盘）[预留]
└── dms-app/                          # 启动模块（打包入口、DB迁移、静态资源）
```

### 2.2 模块职责矩阵

| 模块 | 表前缀 | API前缀 | 职责 | 状态 |
|------|--------|---------|------|------|
| dms-common | 无 | 无 | 跨模块接口定义、DTO、枚举、异常、基类 | ✅ 已实现 |
| dms-masterdata | `md_` | `/api/v1/md` | 医院管理、煎药方案管理 | ✅ 已实现 |
| dms-system | `sys_` | `/api/v1/sys` | 用户管理、系统配置、操作日志 | ✅ 已实现 |
| dms-equipment | `eq_` | `/api/v1/eq` | 设备注册、状态监控、MQTT接入、温度告警 | ✅ 已实现 |
| dms-production | `prod_` | `/api/v1/prod` | 处方接收、任务状态机、工序记录、交接 | ✅ 已实现 |
| dms-quality | `qt_` | `/api/v1/qt` | 质检执行、质检记录查询 | ✅ 已实现 |
| dms-print | `prt_` | `/api/v1/prt` | 打印任务提交、队列管理、重试 | ✅ 已实现 |
| dms-analytics | `ops_` | `/api/v1/ops` | 产能报表、设备利用率、人员绩效 | ⏳ 预留 |
| dms-app | 无 | 无 | Spring Boot启动、Flyway迁移、静态资源 | ✅ 已实现 |

### 2.3 模块依赖关系

```
                    dms-app (聚合打包)
                         │
    ┌────────┬───────┬───┼───┬────────┬────────┬──────────┐
    ▼        ▼       ▼   ▼   ▼        ▼        ▼          ▼
 master   system  equip prod quality print  analytics  common
  data                                                     ▲
    │        │       │    │     │       │        │         │
    └────────┴───────┴────┴─────┴───────┴────────┴─────────┘
                      全部依赖 dms-common

跨模块调用（通过 common 中定义的接口）:
  dms-production ──调用──▶ EquipmentService (dms-equipment 实现)
  dms-production ──调用──▶ PrintService     (dms-print 实现)
  dms-production ──调用──▶ QualityService   (dms-quality 实现)
  dms-print      ──调用──▶ EquipmentService (dms-equipment 实现)
```

### 2.4 跨模块接口契约（定义在 dms-common）

| 接口 | 实现模块 | 调用方 | 职责 |
|------|---------|--------|------|
| `EquipmentService` | dms-equipment | dms-production, dms-print | 设备查询、状态更新、自动创建 |
| `PrintService` | dms-print | dms-production | 打印任务提交、重试 |
| `QualityService` | dms-quality | dms-production | 质检执行 |

## 5. 核心状态机

### 5.1 任务状态流转

```
待泡药 → 泡药中 → 待煎药 → 煎药中 → 待出液 → 出液中
  → 待包装 → 包装中 → 待贴标 → 待质检 → 待交接 → 已完成
                                  ↓           ↓
                                已报废     已部分完成
```

### 5.2 质检分支

| 质检结果 | 目标状态 | 说明 |
|---------|---------|------|
| 通过 | 待交接 | 正常流转 |
| 让步放行 | 待交接 | 标记异常+原因 |
| 返工 | 待煎药 | 回退重做 |
| 报废 | 已报废 | 标记异常+原因 |

### 5.3 设备状态

| 状态 | 说明 |
|------|------|
| IDLE | 空闲可用 |
| BUSY | 工作中（被任务占用） |
| FAULT | 故障 |
| OFFLINE | 离线 |

## 7. MQTT 集成

| 配置项 | 值 |
|--------|-----|
| Broker | tcp://127.0.0.1:1883 |
| Client ID | dms-backend |
| 订阅 Topic | device/+/status |

### 消息类型

| 类型 | Topic | 方向 | 说明 |
|------|-------|------|------|
| 状态上报 | device/{deviceId}/status | 设备→系统 | 温度、状态 |
| 心跳 | device/{deviceId}/heartbeat | 设备→系统 | 在线检测 |
| 指令下发 | device/{deviceId}/command | 系统→设备 | 启动/停止 |
| 指令响应 | device/{deviceId}/response | 设备→系统 | 执行结果 |
| 故障上报 | device/{deviceId}/fault | 设备→系统 | 故障码 |
