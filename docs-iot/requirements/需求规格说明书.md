## 1. 系统定位

煎药室全流程管理系统，覆盖从处方接收到药品交接的完整生产链路，包含设备物联网接入、生产执行、质量管控、打印管理等能力。

**已实现**：处方→泡药→煎药→出液→包装→贴标→质检→交接 全流程状态机
**待开发**：设备适配器（东华原/三延/仟方/厚达）、数字孪生增强、运营分析

## 3. 下一阶段重点：设备适配器

### 3.1 适配器架构

```
dms-equipment/adapter/
├── DeviceAdapter.java          # 统一适配器接口
├── AdapterRegistry.java        # 适配器注册中心
├── mqtt/
│   ├── QianfangAdapter.java    # 仟方 MQTT
│   └── HoudaAdapter.java      # 厚达 MQTT
└── tcp/
    ├── TcpBinaryAdapter.java   # TCP 二进制基类
    ├── DonghuaYuanAdapter.java # 东华原 TCP
    └── SanyanAdapter.java      # 三延 TCP
```

### 3.2 设备厂商清单

| 厂商 | 设备类型 | 协议 | 优先级 |
|------|---------|------|--------|
| 东华原 | 煎药机 | TCP 二进制 | P0 |
| 三延 | 煎药机 | TCP 二进制 | P0 |
| 仟方 | 煎药机 | MQTT | P0 |
| 厚达 | 煎药机 | MQTT | P0 |
| 东华原 | 包装机 | TCP 二进制 | P1 |
| 三延 | 包装机 | TCP 二进制 | P1 |

### 3.3 适配器接口定义

```java
public interface DeviceAdapter {
    String getManufacturer();
    String getProtocol();
    void connect(DeviceConnectionInfo info);
    void disconnect(String deviceId);
    void sendCommand(String deviceId, DeviceCommand command);
    DeviceStatus parseStatus(byte[] rawData);
}
```
