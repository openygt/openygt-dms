# OpenYGT 煎药室管理系统产品功能说明书（最新版）

| 版本 | V4.0 |
|------|------|
| 日期 | 2026-04-27 |
| 说明 | 基于当前实现能力整理 |

## 1. 产品概述

OpenYGT 煎药室管理系统用于支撑煎药室生产全流程管理，覆盖处方、任务、设备、打印、质检、交接及基础管理能力。

## 2. 功能地图

一级功能：
- 实时看板
- 生产管理
- 设备监控
- 打印中心
- 质量管理
- 消耗流水
- 产能报表
- 基础数据
- 系统管理

## 3. 功能说明

### 3.1 实时看板

功能点：
- 展示今日任务总量
- 展示完成、进行中、待处理任务数
- 展示在线/离线设备数
- 展示活动告警数
- 展示任务状态分布
- 展示设备类型分布

当前说明：
- 可用于值班与演示。
- 其中部分指标仍为简化计算。

### 3.2 处方管理

功能点：
- 新增处方
- 查看处方详情
- 分页查询处方

业务特征：
- 处方创建后会带动生产任务生成。

### 3.3 任务管理

功能点：
- 查看任务列表
- 查看任务详情
- 按状态/设备筛选
- 执行泡药开始/结束
- 执行煎药开始/结束
- 执行出液开始/结束
- 执行包装开始/结束
- 执行贴标确认
- 执行质检
- 执行交接
- 查看步骤日志
- 查看交接明细
- 查看状态历史
- 执行强制状态调整
- 触发打印与打印重试

业务价值：
- 是系统核心操作入口。

### 3.4 消耗流水

功能点：
- 手工或流程触发记录消耗流水
- 按任务查询消耗记录
- 分页查询消耗记录

说明：
- 当前是消耗审计能力，不是完整库存管理。

### 3.5 设备管理

功能点：
- 设备新增、编辑、删除、查询
- 按设备编码查询
- 设备预留
- 设备释放
- 查看设备温度阈值
- 查看温度日志

业务特征：
- 支持自动创建设备档案。
- 支持状态管理、告警与心跳离线。

### 3.6 告警日志

功能点：
- 查询设备告警
- 查看告警内容、级别、处理状态

告警来源：
- 高温
- 低温
- 离线
- 故障

### 3.7 打印中心

功能点：
- 打印任务分页查询
- 打印提交
- 打印重试
- 查看打印队列

当前限制：
- 执行层仍为模拟成功执行。

### 3.8 质检记录

功能点：
- 执行质检
- 查询某任务最新质检结果

业务特征：
- 质检结果驱动任务后续状态。

### 3.9 产能报表

功能点：
- 查询时间范围内的基础产能日报

当前限制：
- 医院过滤未完成。
- 更深层经营分析未完成。

### 3.10 医院管理

功能点：
- 医院新增
- 编辑
- 查询
- 分页
- 删除

### 3.11 煎煮方案管理

功能点：
- 方案新增
- 编辑
- 查询
- 分页

业务价值：
- 为设备温度阈值、工艺参数扩展预留基础。

### 3.12 用户管理

功能点：
- 用户新增
- 编辑
- 查询
- 分页
- 删除
- 登录

说明：
- 密码采用 BCrypt 加密存储。

### 3.13 角色与菜单管理

功能点：
- 角色列表、详情、新增、编辑、删除
- 菜单树查询
- 菜单新增、编辑、删除
- 用户分配角色
- 角色分配菜单

说明：
- 功能已提供，但前后端权限联动未完全闭环。

### 3.14 系统配置

功能点：
- 配置新增
- 编辑
- 查询
- 删除
- 按键获取配置值

### 3.15 系统日志

功能点：
- 操作日志查询

## 4. 典型使用场景

### 场景 1：处方入库到生产完成

步骤：
1. 录入处方
2. 系统自动生成任务
3. 操作员推进泡药、煎药、出液、包装、贴标
4. 质检员完成质检
5. 操作员完成交接

### 场景 2：设备监控

步骤：
1. 设备通过 MQTT 上报状态或温度
2. 系统更新设备状态与心跳
3. 超阈值时生成告警
4. 看板和告警页面展示结果

### 场景 3：打印补打

步骤：
1. 对任务发起打印
2. 若失败则发起重试
3. 系统记录打印任务与执行记录
