# kimi01 任务单: 测试方案设计

> Sprint 1 任务: 测试方案
> 截止: 收到本任务单后 2 天内
> 产出: `docs/tasks/kimi01-测试方案.md`

## 背景

下一阶段将新增设备适配器、设备影子、心跳检测、煎药方案管理等功能。你需要提前设计测试方案，与开发并行编写测试用例。

## 测试范围

### 1. 适配器测试（配合 kimi02/kimi03）
- DeviceAdapter 接口的 Mock 测试
- AdapterRegistry 路由选择测试
- TCP 适配器连接/断开/指令下发测试
- MQTT 适配器消息解析测试

### 2. 设备影子测试（配合 kimi03）
- reported 状态更新测试
- desired 状态设置测试
- 影子版本号管理测试

### 3. 心跳超时测试（配合 kimi03）
- 心跳正常场景
- 心跳超时自动离线场景
- 设备重新上线恢复场景

### 4. CRUD 接口测试（配合 kimi04）
- 煎药方案 CRUD
- 系统配置 CRUD
- 操作日志查询

### 5. 回归测试
- 现有 20 个测试用例全部通过
- simulator.py V3 全流程通过
- 新功能不影响现有流程

## 测试方案要求

请设计测试方案文档，包含:

1. 测试用例清单（编号、描述、前置条件、步骤、预期结果）
2. 测试数据准备方案
3. Mock 策略（TCP/MQTT 连接如何 Mock）
4. 覆盖率目标（> 80%）
5. 回归测试检查清单

## 提交方式

完成后更新 `docs/tasks/kimi01-reply.md` 通知架构师审核。
